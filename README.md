# Lisbon Guide 🌍🇵🇹

A web-based guide designed to help users explore Lisbon, discover attractions, plan itineraries, and get practical travel information in one place.

---

## 📌 Overview

This project is a Lisbon travel guide application that provides curated information about:

- Tourist attractions
- Neighborhoods
- Restaurants & cafés
- Transportation
- Suggested itineraries
- Local tips and recommendations

The goal is to simplify trip planning and enhance the visitor experience in Lisbon.

---

## 🚀 Features

- 📍 **Interactive city guide** with key points of interest  
- 🗺️ **Neighborhood breakdown** (e.g., Alfama, Bairro Alto, Belém)  
- 🍽️ **Food & drink recommendations**  
- 🏛️ **Attraction highlights** with descriptions  
- 🧭 **Suggested itineraries** (1-day, 3-day plans, etc.)  
- 💡 **Travel tips** (transport, safety, best time to visit)  
- 🔍 Easy navigation and structured content
